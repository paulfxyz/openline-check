# Openline eSIM Compatibility Check

Openline's browser-based explorer for eSIM support: search 9,496 phones, tablets, smartwatches and hotspots from 173 brands by name or model code, with typo-tolerant matching and regional caveats.

This repository keeps the original September 2026 snapshot for history. Development, releases, issues and the production deployment all live in [askopenline/openline-check](https://github.com/askopenline/openline-check).
